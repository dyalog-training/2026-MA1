# 2026-MA1
These are the pre-requisites materials for the Dyalog '26 workshop MA1: Web Services in APL: An Introduction to REST and OpenAPI. You need Dyalog APL 20.0 or later.

Clone this repository or [download as a .zip](https://github.com/dyalog-training/2026-MA1/archive/refs/heads/main.zip) before the workshop.

## Overview

This workshop introduces web services in Dyalog APL: calling them, and providing them.

1. Basics: HTTP, REST and HttpCommand
1. Consuming: OpenAPI and generated clients
1. Serving: Jarvis and Stark

## Learning Objectives

- Understand how REST uses URLs, HTTP methods and status codes
- Call a web service from APL using a client generated from its OpenAPI specification
- Read a response to tell success from failure
- Expose APL functions as a web service with an OpenAPI specification
