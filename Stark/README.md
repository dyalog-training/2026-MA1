# Stark
[Stark](https://github.com/dyalog-labs/stark) 0.2.4 and the [Jarvis](https://github.com/Dyalog/Jarvis) 1.22.6 it runs on, as published on [tatin.dev](https://tatin.dev). Both are MIT-licensed; see `LICENSE-Stark` and `LICENSE-Jarvis`.

## Setup and Use
Stark looks for Jarvis beside itself, so use Link to import both into the same namespace.

```apl
      ]LINK.Import # /path/to/Stark
```
