# Open-Meteo
An APL client for the [Open-Meteo](https://open-meteo.com) weather forecast API, generated from its OpenAPI specification `forecast.yml` by the [Dyalog OpenAPI client generator](https://github.com/dyalog-labs/OpenAPI).

## Setup and Use
Use Link to import the client into your active workspace.

```apl
      ]LINK.Import OpenMeteo /path/to/OpenMeteo/APLSource
```
