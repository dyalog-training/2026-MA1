# Quotations
An APL client for the quotations service that runs during the workshop, generated from its OpenAPI specification `openapi.json` by the [Dyalog OpenAPI client generator](https://github.com/dyalog-labs/OpenAPI).

## Setup and Use
Use Link to import the client into your active workspace.

```apl
      ]LINK.Import Quotations /path/to/Quotations/APLSource
```
